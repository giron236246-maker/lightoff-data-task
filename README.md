## 快速运行

Windows PowerShell，在本仓库目录中执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe analysis.py data/task.csv
```

将命令中的文件名替换为实际 CSV 路径。脚本生成 `outputs/data_profile.json`，包含行列数、完全重复的记录数、各字段空白值及非空唯一值数量。默认依次尝试 UTF-8 和 GB18030，也可通过 `--encoding` 指定编码。

脚本保留字段的文本形式和标识符前导零；空白指空字符串或纯空格，`NA`、`null` 等文本不会自动当作缺失值。数据默认不上传 GitHub；是否可以公开原始数据，以任务要求为准。原始数据未公开时，复现者需自行获取同一份数据。
